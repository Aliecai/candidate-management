AI Usage Documentation

AI tools were used as supporting tools during the development of the Candidate Management System. The application design, implementation, and integration were primarily carried out by the developer.

AI assistance was used selectively for the following activities:

1. Requirement Understanding

   Used AI to clarify a few project requirements.
   Discussed possible approaches for implementing certain features.

2. Initial Code Structure

   Took assistance from AI in generating some initial Spring Boot boilerplate code.
   Used AI suggestions for project configuration and Maven dependencies.

3. Testing

   Used AI to get suggestions for unit test cases.
   Reviewed and modified the suggested test cases according to the application implementation.

4. Logging and Exception Handling

   Took assistance from AI in identifying appropriate logging levels and useful logging points.
   Discussed approaches for centralized exception handling and meaningful error responses.

5. Documentation

   Used AI to improve the README and prepare this AI usage documentation.
